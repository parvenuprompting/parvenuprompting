## Waar ik goed in ben

De meeste AI-tools werken op goed vertrouwen: een prompt, een aanname, hopen dat het klopt. Ik bouw de controle eromheen — code die weigert, een agent die niets mag zonder bevestigde scope en bewijs.

Geen adviesrapporten en geen tussenlagen. Ik lever het product: website, app, backend of pijplijn, van ontwerp tot oplevering.
